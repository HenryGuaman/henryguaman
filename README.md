# Henry Guaman

**Ingeniero en Ciencias de la Computacion — Desarrollador Full Stack
(Java / Spring Boot · React)**

Cuenca, Azuay, Ecuador

Construyo APIs REST y las interfaces que las consumen, para sistemas que ya estan en
produccion: arquitectura en capas, seguridad con JWT, integracion con sistemas legados
y cobertura de pruebas.

---

### Que hago hoy

- **Backend en Java 17 / Spring Boot 3.2** — desarrollo del modulo de vinculacion
  universitaria: proyectos de extension, convenios institucionales, adendas y el ciclo
  de vida de los proyectos. API REST consumida por un ERP en PHP.
- **Integracion entre sistemas** — capa anticorrupcion (ACL) para consumir datos
  academicos del ERP sin acoplar el dominio propio a su esquema.
- **Seguridad y datos** — autenticacion JWT stateless con Spring Security,
  JPA/Hibernate sobre PostgreSQL, auditoria automatica de entidades.
- **Frontend en React 18** — interfaces del ERP universitario con Material UI,
  react-hook-form y React Router. Los bundles se compilan por pagina con webpack y se
  inyectan en las vistas del ERP legado en PHP (mas un modo Vite para desarrollo agil),
  con i18n en i18next (ES/EN), grillas de datos y capa de servicios en Axios.
- **Reportes** — generacion de PDFs (iText + Thymeleaf) y hojas de calculo (Apache POI).
- **Pruebas** — JUnit 5, Mockito y H2; tests de servicio, controlador y repositorio.

Antes: sistemas de control de inventarios (backend Java + frontend Angular/TypeScript)
y proyectos de vision por computadora / machine learning con Python.

---

### Stack

**Backend**
Java 17 · Spring Boot 3.2 · Spring Security · Spring Data JPA / Hibernate · REST APIs

**Base de datos**

**Frontend**
